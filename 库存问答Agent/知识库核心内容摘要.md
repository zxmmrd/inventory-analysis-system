## 二、安全库存模型

### 2.1 模型选择：订单量级安全系数法
本项目采用"订单量级安全系数法"计算安全库存，即以平均日需求量 × 安全系数作为安全库存量。不同类别使用不同的安全系数：
- A 类商品：安全系数 = 2.0（对应较高服务水平）
- B 类商品：安全系数 = 1.0（对应中等服务水平）
- C 类商品：安全系数 = 0.5（对应较低服务水平）

### 2.2 计算公式
安全库存 = 平均日需求量 × 安全系数

### 2.3 设计逻辑
- A 类商品价值高、缺货损失大，因此设置较高的安全系数以保证高服务水平
- C 类商品价值低、缺货影响小，因此降低安全系数以节约库存成本
- 这种差异化策略体现了"分类管理、资源优化配置"的库存管理核心理念

## 三、EOQ 经济订货批量模型

### 3.1 模型定义
EOQ（Economic Order Quantity，经济订货批量）是通过平衡订货成本和持有成本，找到使总库存成本最低的订货批量。

### 3.2 公式
EOQ = √(2DS / H)
其中：
- D = 年需求量（件/年）
- S = 每次订货成本（元/次）
- H = 单位商品年持有成本（元/件·年）

### 3.3 本项目参数
- 订货成本 S = 50 元/次
- 年持有成本率 = 25%
- 单位商品年持有成本 H = 商品单价 × 25%

### 3.4 计算示例
假设某商品年需求量 D = 1,200 件，单价 = 100 元：
- 订货成本 S = 50 元/次
- 单位持有成本 H = 100 × 25% = 25 元/件·年
- EOQ = √(2 × 1200 × 50 / 25) = √(4800) ≈ 69 件
- 即每次订货约 69 件时，总库存成本最低

## 五、间歇性需求特征与处理方法

### 5.1 什么是间歇性需求
间歇性需求（Intermittent Demand），也叫不规则需求，指需求发生的时间不连续，有大量零需求时期的需求模式。常见于慢销品、备件、专用设备等。

### 5.2 主要特征
- 需求时间间隔不规律，零需求天数占比高
- 发生需求时需求量波动大
- 传统的移动平均、指数平滑等预测方法效果不佳
- 安全库存难以设定，容易导致库存积压或缺货

### 5.3 常用处理方法
1. Croston 方法：分别预测需求间隔和需求量，再合并得到最终预测
2. 合成方法（SBA）：在 Croston 基础上进行偏差修正
3. 需求分类管理：按需求频率和变异性将 SKU 分类，采用不同策略
4. 增加安全库存缓冲：对于关键间歇性需求商品，适当提高安全库存

### 5.4 本项目中的处理
- 对 C 类商品中的间歇性需求 SKU，采用简化的安全库存策略
- 通过较低的服务水平目标（87%）来平衡库存成本
- 对于特别重要的间歇性需求备件，建议升级为 A 类管理

## 六、核心业务指标定义

### 6.1 服务水平（Service Level）
- 定义：在一定时期内，能够立即满足的客户需求占总需求的比例
- 公式：服务水平 = 1 - 缺货量 / 总需求量
- 含义：衡量库存系统满足需求的能力，越高表示缺货越少
- 本项目整体服务水平：93.79%

### 6.2 库存周转率（Inventory Turnover）
- 定义：一定时期内库存被销售或使用的次数
- 公式：周转率 = 年销售成本 / 平均库存价值
- 含义：衡量库存周转速度，越高表示资金占用效率越高
- 本项目周转率：1.75 次/年

### 6.3 ROP（再订货点，Reorder Point）
- 定义：当库存水平下降到某一数量时需要发出补货订单，这个数量就是 ROP
- 公式：ROP = 平均日需求量 × 交货期 + 安全库存
- 含义：确定何时发出订货的关键指标

### 6.4 安全库存（Safety Stock）
- 定义：为了应对需求不确定性和供应延迟而额外持有的库存
- 作用：防止缺货，提高服务水平
- 代价：增加持有成本，需要与服务水平权衡
- 本项目采用订单量级安全系数法计算

### 6.5 EOQ（经济订货批量）
- 定义：使总库存成本（订货成本 + 持有成本）最低的订货批量
- 公式：EOQ = √(2DS / H)
- 含义：平衡订货频次与批量，优化总成本

### 6.6 缺货率（Stockout Rate）
- 定义：发生缺货的比例
- 公式：缺货率 = 1 - 服务水平
- 与服务水平互为补充

### 6.7 订货成本（Ordering Cost）
- 定义：每次发出订货订单所产生的成本，包括采购人员费用、通讯费用、运输费用等
- 本项目取值：50 元/次

### 6.8 持有成本率（Holding Cost Rate）
- 定义：单位库存价值一年的持有成本占库存价值的比例
- 包括仓储费、保险费、损耗、资金成本等
- 本项目取值：25%

## 七、需求预测模块

### 7.1 方法
- Croston：分别平滑"订单间隔"和"单次订单量"，适合间歇性需求
- SMA（简单移动平均）：训练期总销量/训练天数，作为对比基线

### 7.2 评估指标
- MAE（平均绝对误差）：预测值与实际值的平均偏差
- RMSE（均方根误差）：大误差的惩罚更大
- MASE（平均绝对缩放误差）：<1 说明比"用上一年直接预测"更好

### 7.3 本项目结果
- 评估SKU数：814个（训练期非零订单>=4次且2018年有需求）
- Croston MAE：14.7，SMA MAE：11.9
- SMA MASE：0.80，说明优于用2017年直接预测
- 结论：当前数据低频特征明显，Croston优势需要更长历史序列才能发挥
