## 一、ABC 分类方法与结果

### 1.1 分类方法
ABC 分类（帕累托分类）基于"关键的少数和次要的多数"原理，将 SKU 按年度消耗金额从高到低排序，划分为 A、B、C 三类：
- A 类：累计金额占比前 70% 的 SKU，需要重点管理
- B 类：累计金额占比 70%-90% 的 SKU，需要常规管理
- C 类：累计金额占比后 10% 的 SKU，可以简化管理

### 1.2 分类结果
本项目共包含 899 个 SKU，分类结果如下：
- A 类：364 个 SKU，金额占比 69.9%
- B 类：249 个 SKU，金额占比 20.0%
- C 类：286 个 SKU，金额占比 10.1%

### 1.3 差异化管理策略
- A 类：严格的库存控制、较高的安全库存水平、频繁盘点、优先补货
- B 类：正常的库存控制、中等安全库存、定期盘点、标准补货流程
- C 类：简化的库存控制、较低安全库存、减少盘点次数、批量订货降低管理成本

## 二、安全库存模型

### 2.1 模型选择：订单量级安全系数法
本项目采用"订单量级安全系数法"计算安全库存，即以平均单次订单量 × 安全系数作为安全库存量。不同类别使用不同的安全系数：
- A 类商品：安全系数 = 2.0（对应较高服务水平）
- B 类商品：安全系数 = 1.0（对应中等服务水平）
- C 类商品：安全系数 = 0.5（对应较低服务水平）

### 2.2 计算公式
安全库存 = 平均单次订单量 × 安全系数

### 2.3 设计逻辑
- A 类商品价值高、缺货损失大，因此设置较高的安全系数以保证高服务水平
- C 类商品价值低、缺货影响小，因此降低安全系数以节约库存成本
- 这种差异化策略体现了"分类管理、资源优化配置"的库存管理核心理念

### 2.4 为什么不用经典正态分布模型
经典安全库存公式：安全库存 = Z × σ_demand × √LT，其中 Z 为服务水平系数，σ_demand 为日需求标准差，LT 为提前期。
但该公式假设需求服从正态分布，而本项目数据为间歇性需求（大量零需求天数），正态分布假设不成立，强行使用会导致：
- 标准差计算失真（大量零值拉低均值和标准差）
- 安全库存严重不足或过量
- 服务水平无法达到预期

因此改用订单量级安全系数法，基于单次订单规模而非日需求波动来设定缓冲，更适合间歇性需求场景。

## 三、EOQ 经济订货批量模型

### 3.1 模型定义
EOQ（Economic Order Quantity，经济订货批量）是通过平衡订货成本和持有成本，找到使总库存成本最低的订货批量。

### 3.2 公式
EOQ = √(2DS / H)
其中：
- D = 年需求量（件/年）
- S = 每次订货成本（元/次）
- H = 单位商品年持有成本（元/件·年）

### 3.3 本项目参数
- 订货成本 S = 50 元/次
- 年持有成本率 = 25%
- 单位商品年持有成本 H = 商品单价 × 25%

### 3.4 计算示例
假设某商品年需求量 D = 1,200 件，单价 = 100 元：
- 订货成本 S = 50 元/次
- 单位持有成本 H = 100 × 25% = 25 元/件·年
- EOQ = √(2 × 1200 × 50 / 25) = √4800 ≈ 69 件
- 即每次订货约 69 件时，总库存成本最低

### 3.5 总成本组成
总库存成本 = 订货成本 + 持有成本
- 订货成本 = (D / Q) × S  （订货次数 × 每次订货成本）
- 持有成本 = (Q / 2) × H  （平均库存 × 单位持有成本）
- EOQ 点是两条成本曲线的交点，即订货成本 = 持有成本时总成本最低

## 四、补货模拟结果

### 4.1 模拟方法
采用逐日滚动模拟方法：
1. 初始化每个 SKU 的初始库存
2. 每一天：扣除当日销量 → 检查库存是否低于 ROP → 低于则触发补货
3. 补货需要经过提前期（lead_time = 4 天）后到货
4. 记录每日库存水位、缺货量、订货记录
5. 模拟周期为一年，统计最终指标

ROP（再订货点）= 平均日需求量 × 提前期 + 安全库存

### 4.2 整体表现
- 整体服务水平：93.79%
- 库存周转率：1.75 次/年
- 总订单数：约 2496 单

### 4.3 分品类结果
- A 类：351 个 SKU 纳入统计，服务水平 99.79%，缺货量 24.5，周转率 1.36
- B 类：236 个 SKU 纳入统计，服务水平 93.50%，缺货量 408.5，周转率 2.05
- C 类：263 个 SKU 纳入统计，服务水平 87.09%，缺货量 725.5，周转率 2.00

### 4.4 结果解读
- A 类商品接近 100% 的服务水平，确保了高价值商品的供应稳定性
- C 类商品 87% 的服务水平在可接受范围内，有效降低了整体库存持有成本
- 整体 93.79% 的服务水平与 1.75 次/年的周转率达到了较好的平衡
- 验证了 ABC 分类管理 + 差异化安全库存策略的有效性
- 周转率呈现 C > B > A 的规律，因为 A 类安全库存高、持有量大，周转率相对低

## 五、间歇性需求特征与处理方法

### 5.1 什么是间歇性需求
间歇性需求（Intermittent Demand），也叫不规则需求，指需求发生的时间不连续，有大量零需求时期的需求模式。常见于慢销品、备件、专用设备等。

### 5.2 主要特征
- 需求时间间隔不规律，零需求天数占比高
- 发生需求时需求量波动大
- 传统的移动平均、指数平滑等预测方法效果不佳
- 安全库存难以设定，容易导致库存积压或缺货

### 5.3 本项目中的间歇性需求特征
- 共 899 个 SKU，9800 条订单，平均每个 SKU 每年约 10-11 条订单
- 约 85% 以上的 SKU 年均订单 ≤ 3 次
- 订单间隔天数差异极大，从 1 天到上百天不等
- 单次订单量差异也很大，从几件到几百件不等

### 5.4 常用处理方法
1. Croston 方法：分别预测需求间隔和需求量，再合并得到最终预测
2. 合成方法（SBA）：在 Croston 基础上进行偏差修正
3. 需求分类管理：按需求频率和变异性将 SKU 分类，采用不同策略
4. 增加安全库存缓冲：对于关键间歇性需求商品，适当提高安全库存

### 5.5 本项目中的处理策略
- 采用订单量级安全系数法，绕开需求率和标准差的正态分布假设
- A 类商品设置较高安全系数（2.0 倍），保障高价值商品的服务水平
- C 类商品降低安全系数（0.5 倍），接受较低服务水平以控制库存成本
- 通过补货模拟验证整体策略的有效性

## 六、核心业务指标定义

### 6.1 服务水平（Service Level）
- 定义：在一定时期内，能够立即满足的客户需求占总需求的比例
- 公式：服务水平 = 1 - 缺货量 / 总需求量
- 含义：衡量库存系统满足需求的能力，越高表示缺货越少
- 本项目整体服务水平：93.79%

### 6.2 库存周转率（Inventory Turnover）
- 定义：一定时期内库存被销售或使用的次数
- 公式：周转率 = 年销售成本 / 平均库存价值
- 含义：衡量库存周转速度，越高表示资金占用效率越高
- 本项目周转率：1.75 次/年

### 6.3 ROP（再订货点，Reorder Point）
- 定义：当库存水平下降到某一数量时需要发出补货订单，这个数量就是 ROP
- 公式：ROP = 平均日需求量 × 交货期 + 安全库存
- 含义：确定何时发出订货的关键指标

### 6.4 安全库存（Safety Stock）
- 定义：为了应对需求不确定性和供应延迟而额外持有的库存
- 作用：防止缺货，提高服务水平
- 代价：增加持有成本，需要与服务水平权衡
- 本项目采用订单量级安全系数法计算

### 6.5 EOQ（经济订货批量）
- 定义：使总库存成本（订货成本 + 持有成本）最低的订货批量
- 公式：EOQ = √(2DS / H)
- 含义：平衡订货频次与批量，优化总成本

### 6.6 缺货率（Stockout Rate）
- 定义：发生缺货的比例
- 公式：缺货率 = 1 - 服务水平
- 与服务水平互为补充

### 6.7 订货成本（Ordering Cost）
- 定义：每次发出订货订单所产生的成本，包括采购人员费用、通讯费用、运输费用等
- 本项目取值：50 元/次

### 6.8 持有成本率（Holding Cost Rate）
- 定义：单位库存价值一年的持有成本占库存价值的比例
- 包括仓储费、保险费、损耗、资金成本等
- 本项目取值：25%

### 6.9 ABC 分类
- 定义：根据 SKU 的价值贡献（通常是销售额或消耗量）将库存分为 A、B、C 三类
- 原理：帕累托法则（80/20 法则），少数高价值 SKU 贡献了大部分销售额
- 目的：对不同类别采用差异化的管理策略，优化资源配置
